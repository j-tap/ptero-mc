# Почему yarn.lock из git не парсится

## Ошибка

При `yarn install` с lockfile из репозитория:

```
SyntaxError: Invalid value type 2355:0 in /var/www/pterodactyl/yarn.lock
```

## Возможные причины

1. **Другая версия Yarn** — lockfile мог быть создан другой минорной версией Yarn 1.x. Парсер в 1.22.22 иногда падает на файлах, созданных старыми версиями (известный баг: [yarn#6152](https://github.com/yarnpkg/yarn/issues/6152)).
2. **Кросс-платформа** — если lockfile правили и на Windows, и в Linux/Docker, в файле могли появиться записи без кавычек у `resolved` или другие отличия формата.
3. **Случайный символ** — в таких ошибках парсер часто указывает не на реальное место поломки (например, лишний символ в середине файла, а ошибка — на другой строке).

Содержимое вокруг строки 2355 в нашем lockfile выглядит корректно (стандартный блок `ajv-keywords` / `ajv`), явной порчи не видно.

## Как вернуть старый набор зависимостей

### Вариант A: другая версия Yarn

Проверено: с lockfile из git падают **Yarn 1.22.22, 1.21.1 и 1.15.2** с одной и той же ошибкой `Invalid value type 2355:0`. Старый lockfile в репозитории, скорее всего, повреждён или в формате, который текущие Yarn 1.x не принимают. Пробовать ещё более старые версии (1.10, 1.9) можно, но надёжного способа «починить» такой файл нет.

### Вариант B (рекомендуется): оставить текущий lockfile

После удаления битого lockfile был выполнен `yarn install` — получился **новый** lockfile. С ним панель собирается и работает. Версии пакетов могут отличаться от тех, что были в git.

**Рекомендация:** не восстанавливать `yarn.lock` из git. Использовать текущий рабочий lockfile и **закоммитить его** в репозиторий, чтобы в истории был валидный файл:

```bash
git add yarn.lock
git commit -m "chore: replace broken yarn.lock with valid one"
```

### Вариант C: взять lockfile из старого коммита

Если знаете коммит, когда всё работало:

```bash
git show <старый-коммит>:yarn.lock > yarn.lock
yarn install
```

Если с этим файлом `yarn install` тоже падает — попробовать с ним вариант A (Yarn 1.21.1).
